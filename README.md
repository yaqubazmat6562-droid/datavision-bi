\# 📊 DATAVISION BI



A modern, AI-powered Business Intelligence platform that transforms Excel/CSV data into beautiful dashboards with KPIs, charts, and automated insights.



\## 🚀 Live Demo



\*\*\[https://datavision-bi-xxxx.onrender.com](https://datavision-bi-xxxx.onrender.com)\*\*



\## ✨ Features



\- 📁 \*\*Universal File Support\*\* — Upload any Excel/CSV file

\- 🧠 \*\*Smart Column Detection\*\* — Auto-detects sales, cost, product, customer columns

\- 📊 \*\*Auto Dashboard\*\* — 8 KPIs + 7 interactive charts

\- 🎨 \*\*Dynamic Chart Types\*\* — Bar, Line, Pie, Doughnut, Polar, Radar

\- 🎛️ \*\*Interactive Filters\*\* — Product, Category, State, City, Date range

\- 🌍 \*\*20+ Currencies\*\* — Universal currency support

\- 📤 \*\*Multi-format Export\*\* — PDF, Excel, CSV, JSON

\- 🧹 \*\*Data Cleaning\*\* — Auto quality report

\- 🔍 \*\*Data Explorer\*\* — Column profiling, search, filters

\- ⚡ \*\*Power Query Editor\*\* — Transform data like Power BI

\- 🔐 \*\*User Accounts\*\* — Signup, login, secure sessions



\## 🛠️ Tech Stack



\- \*\*Backend:\*\* Flask, Python 3.11

\- \*\*Database:\*\* PostgreSQL (Render)

\- \*\*Frontend:\*\* Vanilla JS, Chart.js

\- \*\*PDF Generation:\*\* ReportLab, Matplotlib

\- \*\*Deployment:\*\* Render.com
